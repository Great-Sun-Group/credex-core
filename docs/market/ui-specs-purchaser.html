Purchaser User Interface Specifications

These screens allow purchasers to issue payment and browse products, stores, and vendors in the Vimbiso Market.

Offer Credex

This screen allows purchasers to offer a credex in response to an invoice.

Components:
  • Read-only offerCredex screen
  • Values (including list of accounts and amounts) filled out from /getInvoice
  • Sign & Send button /createCredex

Search Screen

This screen allows purchasers to search for items, stores, and vendors in the Vimbiso Market.

Components:
  • Search b /searchProducts
  • Map box with near me and results
  • List of results (clicks to view Item, Store, Vendor pages)

Search returns:

  • Products with location and link to product page to be displayed on on map and in list below map with links.
  • Links to stores and members are within product pages, not here.
