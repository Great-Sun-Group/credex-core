Testing Progress

Completed Tests ✅
  • Member Onboarding - Successfully tested creating new members with personal accounts: 
    npm test onboardmember Fortunate Vendor 1234567890 USD
    or if already onboarded to get token: 
    npm test login 1234567890
  • Edit Member Profile - Successfully tested updating member profile information with /editMember endpoint 
    npm test editmember tokenHere "New First" "New Last" "NEWHANDLE" "Updated vendor bio with more details"
    • Verified updating all fields at once (first name, last name, member handle, and vendor bio)
    • Verified updating individual fields separately (single field updates)
    • Confirmed proper validation for member handle (uppercase letters, numbers, and underscores only)
    • Tested with curl to verify API behavior: 
      curl -X POST http://localhost:3000/editMember -H "Content-Type: application/json" -H "Authorization: Bearer token" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"vendorBio": "Testing single field update"}'
  • Vendor Enablement - Successfully tested enabling vendor functionality with /sellInMarket endpoint 
    npm test sellinmarket tokenHere true
    • Verified creation of "Onboarded Assets" account (PRODUCTION type)
    • Verified creation of "Profile Pictures" account (DIGITAL_ASSET type)
  • Product Account Creation - Successfully tested creating product accounts with /createAccountInternal endpoint 
    npm test createAccountInternal tokenHere "Fresh Tomatoes" USD PHYSICAL_ASSET
    • Verified creation of product account with PHYSICAL_ASSET type
    • Verified proper ownership relationship to member
  • Image Upload - Successfully tested uploading and optimizing profile images with /uploadAndOptimizeJpg endpoint

    • Verified creation of original, thumbnail, 200px, and 600px versions

    • Verified USED_IN relationships between image versions

    curl -X POST http://localhost:3000/editAccountInternal -H "Content-Type: application/json" -H "Authorization: Bearer token" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"accountID": "accountID", "accountName": "Updated Product Name"}'
    • Verified updating all fields at once (account name, description, handle)
    • Verified updating individual fields separately (single field updates)
    • Confirmed proper sanitization for account handle (converts lowercase to uppercase, removes spaces and special characters)

  • Store Status Management - Successfully tested updating store status and location with /storeStatus endpoint 
    curl -X POST "http://localhost:3000/storeStatus/accountID" -H "Content-Type: application/json" -H "Authorization: Bearer token" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"storeOpen": true, "location": {"latitude": 17.8252, "longitude": 31.0335}}'
    • Verified opening store with location coordinates
    • Verified closing store (setting storeOpen to false)
    • Confirmed validation of location data when store is open

    • Verified search by product name/keyword

  • Account Internal Data - Successfully tested retrieving account internal data with /getAccountInternalData endpoint
