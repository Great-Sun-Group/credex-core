Textract Development Guide

for the credex-core API

Overview

The credex-core API uses AWS Textract for document analysis in the verification process. This guide covers the development workflow and testing approaches for Textract integration.

Local Development Challenges

Developing with AWS Textract presents unique challenges because:

  • Textract is a cloud service that can't be run locally
  • Permissions are managed by the ECS task role in deployed environments
  • Local development requires AWS credentials with Textract permissions

Development Workflow

1. Infrastructure Setup

Before starting development:

  • Textract permissions have been deployed to AWS "development" environment.

2. Local Development Setup

For local development, you need:

  • AWS credentials with Textract permissions (can use AWS CLI profile)
  • Environment variables:
    • AWS_PROFILE=your-dev-profile
    • AWS_REGION=af-south-1
    • VERIFICATION_PHOTOS_BUCKET=credex-verification-photos-development

Testing Approaches

Local Testing with Dev Infrastructure

This approach allows rapid development while using cloud resources:

  • Run your local app using dev AWS credentials
  • Upload test documents to the dev S3 bucket
  • Your local code can then use Textract through your AWS credentials
  • Good for rapid development and debugging

Full Integration Testing

For complete end-to-end testing:

  • Deploy both infrastructure and app changes to development
  • Test through the deployed API
  • This tests the complete flow including ECS task role permissions

Development Tips

  • Start with the infrastructure deployment to enable Textract access
  • Use real ID document samples (test data) stored in development S3
  • Log Textract responses extensively during development
  • Consider creating test endpoints specifically for Textract testing

Common Development Tasks

  • Testing new document types: Upload to dev S3, analyze Textract response
  • Debugging field extraction: Use AWS Console to view raw Textract results
  • Performance testing: Monitor API latency in development environment

This hybrid approach (local code + dev infrastructure) lets you develop and test Textract integration effectively while maintaining security of AWS resources.
