Seller User Interface Specifications

These screens allow vendors to manage their profiles, products, and transactions in the Vimbiso Market.

First-Time User Experience

The first time a member goes to the market, they will see a single screen with a button saying "Open My Vimbiso Market Store". When clicked, this button hits the /sellinmarket endpoint, then takes member to Store.

Vimbiso Store Home

This screen allows vendors to manage their store settings and create invoices for customers in the Vimbiso Market.

Components:
  • Store Header with store name and thumbnail image on same line
  • Open My Store and Share My Location button. When clicked, changes to Close My Store and Make My Location Private. Hits /storeStatus endpoint, then pings with any changes in location.
  • Create Credex Invoice section. This section loads all accounts with type PHYSICAL_ASSET
  • Add Product link when no PHYSICAL_ASSET accounts exist.
  • Generate Credex Invoice QR button - Hits /generateInvoice
  • Navigation to Vimbiso Store Management

Vimbiso Store Management

This screen allows vendors to manage their product offerings and account balances in the Vimbiso Market.

Components:
  • Store Header section
    • Store name with thumbnail image on same line
    • Edit buttons for both name and image
  • Store Description section (displayed below accounts)
    • Store description with edit button
  • Product Accounts section
    • Add and edit accounts for items you sell
    • Can be single items (e.g., "2018 Toyota") or flows of items (e.g., "Fresh Tomatoes")
  • Controls
    • Add Account button (always visible)
    • List of Accounts and Balances, totaled at the bottom
    • Tap an account to view/edit
    • Adjust Balances button (to be added later)
  • Navigation back to Vimbiso Store Home

Credex Invoice QR Code

This screen displays a QR code that can be scanned by customers or printed. It is an invoice that links to internal accounts and can be used multiple times by multiple customers if desired.

Components:
  • QR code - A scannable QR code that contains the invoice information
  • Invoice details - Summary of the invoice items and total
  • Shareable link - URL that can be shared with customers
  • Action buttons - Options to copy link or close the QR code

Manage Product Account

This screen allows vendors to manage a Product account.

Components:
  • Account Name with edit button
  • Media
    • Single photo with add button (triggers /uploadAndOptimizeJpg then /updateProfilePics)
  • Details
    • Product/Account Description (long text)
    • List of most recent 10 transactions in the account
  • Controls
    • Save button
    • Adjust Balances button (to be added later)

Edit Member Profile

This screen allows vendors to edit their Seller profile information.

Components:
  • Profile Information
    • Profile picture
    • Profile pic add button (triggers /uploadAndOptimizeJpg then /updateProfilePics with assetIDs)
    • First name (short text)
    • Last name (short text)
    • Member handle (short text)
    • Vendor bio (long text)
  • Save button - Hits /editMember with text fields
