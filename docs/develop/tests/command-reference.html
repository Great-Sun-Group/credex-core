Command Reference

This page provides a comprehensive reference for all test commands. All commands below can be run against any environment by adding the environment prefix (dev/stage).

DevAdmin Operations

npm test cleardevdbs     # Clear test databases
npm test forcedco        # Force Daily Credcoin Offering
npm test clearforce      # Clear DBs and force DCO
npm test trustaudit      # Run trust account audit

Member Endpoints

# Onboarding and Authentication
npm test onboardmember firstname lastname phone defaultDenom
npm test onboardMemberWithPassword firstname lastname phone defaultDenom password
npm test setInitialPassword phone password                # Set initial password for v1 members
npm test updatePassword phone oldPassword newPassword     # Update existing password
npm test passwordReset phone                              # Test password reset with OTP
npm test login phone [password]                           # Test login (with optional password)

# Member Information
npm test getmemberbyhandle phone memberHandle
npm test getmemberdashboardbyphone phone
npm test editMember token [firstname] [lastname] [memberHandle] [vendorBio]

Market Endpoints

# Enable vendor functionality
npm test sellInMarket token

# Account management
npm test createAccountInternal token accountName [defaultDenom] [accountType]
npm test editAccountInternal token accountID accountName [defaultDenom]
npm test deleteAccountInternal token accountID

# Asset management
npm test addAssetMarker token assetName crAccountID crAmount drAccountID drAmount [denomination] [additionalParams]
npm test uploadAndOptimizeJpg token imagePath name drAccountID [crAccountID]
npm test connectAsset token assetID connectedID relName
npm test disconnectAsset token assetID connectedID relName

# Invoice and payment
npm test generateInvoice token paymentAccountID itemName quantity unit price [currency] [notes]
npm test createCredexWithInvoice token issuerAccountID receiverAccountID denomination initialAmount credexType offersOrRequests secured invoiceID [dueDate]

# Complete market flow
npm test marketFlow

Admin Endpoints

# Run all admin tests together
npm test admin

# Individual admin endpoints
npm test admin getmemberdetails phone memberID
npm test admin getaccountdetails phone accountID
npm test admin updatemembertier phone memberID tier
npm test admin getreceivedcredexoffers phone accountID
npm test admin getsentcredexoffers phone accountID

Account Endpoints

npm test getaccountbyhandle phone accountHandle
npm test getledger phone accountID

Credex Endpoints

npm test createcredex phone amount denom receiverHandle
npm test acceptcredex phone credexID
npm test acceptcredexbulk phone credexIDs
npm test declinecredex phone credexID
npm test cancelcredex phone credexID
npm test getcredex phone credexID

Notification Tests

# Run all notification tests
npm test notifications

# Run specific notification test files
npm test credexNotifications    # Tests credex-related notifications
npm test notificationService    # Tests notification service functionality

Error Case Tests

# Run all error case tests
npm test errors

# This will:
# 1. Create two test accounts
# 2. Run all error case tests with the test accounts
# 3. Clean up test data

Integration Tests

# Run all integration tests
npm test integrate

Command Parameters

Member Endpoints

onboardmember

  • firstname: First name of the member
  • lastname: Last name of the member
  • phone: Phone number (unique identifier)
  • defaultDenom: Default denomination (e.g., USD)

login

  • phone: Phone number of the member
  • password: (Optional) Password for authentication

Market Endpoints

sellInMarket

  • token: JWT token for authentication

createAccountInternal

  • token: JWT token for authentication
  • accountName: Name of the account to create
  • defaultDenom: (Optional) Default denomination (e.g., USD)
  • accountType: (Optional) Account type (e.g., PRODUCTION)

addAssetMarker

  • token: JWT token for authentication
  • assetName: Name of the asset
  • crAccountID: Credit account ID
  • crAmount: Credit amount
  • drAccountID: Debit account ID
  • drAmount: Debit amount
  • denomination: (Optional) Denomination (e.g., USD)
  • additionalParams: (Optional) Additional parameters as key-value pairs or JSON

generateInvoice

  • token: JWT token for authentication
  • paymentAccountID: Account ID to receive payment
  • itemName: Name of the item
  • quantity: Quantity of the item
  • unit: Unit of measurement (e.g., kg, each)
  • price: Price per unit
  • currency: (Optional) Currency (e.g., USD)
  • notes: (Optional) Additional notes

Credex Endpoints

createcredex

  • phone: Phone number for authentication
  • amount: Amount of the credex
  • denom: Denomination (e.g., USD)
  • receiverHandle: Handle of the receiver

acceptcredex

  • phone: Phone number for authentication
  • credexID: ID of the credex to accept

Environment Prefixes

All commands can be run against different environments by adding the environment prefix: 

# Local environment (default)
npm test command [params]

# Development environment
npm test dev command [params]

# Staging environment
npm test stage command [params]

Docker Container Commands

All commands can also be run in a Docker container: 

# Local environment
npm run docker:test command [params]

# Development environment
npm run docker:test dev command [params]

# Staging environment
npm run docker:test stage command [params]

Coverage Commands

# Run all tests with coverage
npm run test:coverage

# Run specific tests with coverage
COVERAGE=true npm test command [params]
