Comprehensive testing plan and progress tracking for the Vimbiso Market API implementation.

Testing Progress

Completed Tests ✅
  • Member Onboarding - Successfully tested creating new members with personal accounts: 
    npm test onboardmember Fortunate Vendor 1234567890 USD
    or if already onboarded to get token: 
    npm test login 1234567890
  • Vendor Enablement - Successfully tested enabling vendor functionality with /sellInMarket endpoint 
    npm test sellinmarket tokenHere true
    • Verified creation of "Onboarded Assets" account (PRODUCTION type)
    • Verified creation of "Profile Pictures" account (DIGITAL_ASSET type)
  • Product Account Creation - Successfully tested creating product accounts with /createAccountInternal endpoint 
    npm test createAccountInternal tokenHere "Fresh Tomatoes" USD PHYSICAL_ASSET
    • Verified creation of product account with PHYSICAL_ASSET type
    • Verified proper ownership relationship to member
  • Image Upload - Successfully tested uploading and optimizing profile images with /uploadAndOptimizeJpg endpoint 
    npm test uploadandoptimizejpg token local/image/url/jpg "profile_pic" "Onboarded Assets accountID" "Profile Pictures accountID"
    • Verified creation of original, thumbnail, 200px, and 600px versions
    • Verified CR relationship to "Onboarded Assets" account
    • Verified DR relationship to "Profile Pictures" account
    • Verified USED_IN relationships between image versions
  • Profile Picture Relationships - Successfully tested connecting multiple profile pictures to member and account source nodes with /updateProfilePics endpoint 
    npm test updateProfilePics token sourceID originalAssetID thumbnailAssetID asset200ID asset600ID
    • Verified PROFILE_PIC_ORIGINAL_JPG relationship creation
    • Verified PROFILE_PIC_THUMBNAIL_JPG relationship creation
    • Verified PROFILE_PIC_200_JPG relationship creation
    • Verified PROFILE_PIC_600_JPG relationship creation
    • Confirmed all connections can be made in a single API call
    • Verified proper disconnection of existing relationships
