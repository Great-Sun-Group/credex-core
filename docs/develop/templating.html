Documentation Site Templating System

How to use and maintain the site templates

This documentation site uses a client-side templating system to maintain consistent design elements across all pages. This guide explains how the system works and how to use it.

Directory Structure

docs/
├── components/           # HTML components for templating
│   ├── header.html       # Site header component
│   ├── nav.html          # Navigation menu component
│   └── footer.html       # Site footer component
├── css/                  # Modular CSS files
│   ├── base.css          # Base styles (typography, colors, etc.)
│   ├── layout.css        # Layout styles
│   ├── components.css    # Component-specific styles
│   ├── navigation.css    # Navigation-specific styles
│   └── responsive.css    # Responsive/mobile styles
├── js/
│   └── template.js       # JavaScript for loading components
├── style.css             # Main CSS file that imports all other CSS files
└── template-index.html   # Example page using the templating system

How It Works

The templating system uses JavaScript to load HTML components into designated containers on each page. This allows for consistent header, navigation, and footer elements across all pages.

Main Features

  1. Modular CSS: Styles are organized into separate files for easier maintenance.
  2. Component-Based Structure: Header, navigation, and footer are defined once and reused across all pages.
  3. Responsive Design: Mobile-friendly navigation with hamburger menu and dropdowns.
  4. Active State Tracking: Automatically highlights the current page in the navigation.

How to Use

Converting an Existing Page

To convert an existing page to use the templating system:

  1. Add container divs for the components:

    <!-- Header Component -->
<div id="header-develop"></div>

<!-- Navigation Component -->
<div id="nav-container"></div>

<!-- Your page content here -->

<!-- Footer Component -->
<div id="footer-develop"></div>

  2. Add the template.js script before the closing body tag:

    <script src="../js/template.js"></script>
<script src="../js/dropdown.js"></script>

  3. Remove any existing menu button or navigation elements that are being replaced.

Creating a New Page

Use template-index.html as a starting point for new pages. Simply copy the file, rename it, and replace the content section with your new content.

Modifying Components

To change the design or content of a component:

  1. Edit the corresponding HTML file in the components/ directory.
  2. Edit the corresponding CSS file in the css/ directory.

For example, to update the navigation menu, edit components/nav.html and css/navigation.css.

Navigation Menu

The navigation menu is a horizontal bar with dropdowns for Develop, Due Diligence, and Trust Again sections. On mobile devices, it collapses into a hamburger menu.

Adding a New Menu Item

To add a new item to the navigation menu, edit components/nav.html and add a new list item to the appropriate section.

For a top-level item:

<li><a href="/path/to/page.html">Menu Item</a></li>

For a dropdown item:

<li><a href="/path/to/page.html">Dropdown Item</a></li>

CSS Organization

The CSS is organized into modular files for easier maintenance:

  • base.css: Typography, colors, and basic element styles
  • layout.css: Layout-related styles (tables, images, etc.)
  • components.css: Styles for specific components (header, footer, etc.)
  • navigation.css: Styles for the navigation menu
  • responsive.css: Mobile-responsive styles

To modify styles, edit the appropriate CSS file rather than the main style.css file.
