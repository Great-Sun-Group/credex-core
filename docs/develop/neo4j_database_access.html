Neo4j Database Access

Credex-core runs on two Neo4j databases. This page provides connection information for accessing these databases directly through the Neo4j Browser interface.

Important: When accessing the Neo4j Browser, you'll need to manually enter these connection URLs to ensure you're connecting to the correct database.

Development Environment

In the development environment, the Neo4j databases are accessible through Docker containers:

Neo4j Ledger Database

Connection URL: localhost:7687

Browser URL: http://localhost:7474/browser/

Neo4j Search Database

Connection URL: localhost:7688

Browser URL: http://localhost:7475/browser/

Production Environment

In the production environment, the Neo4j databases are deployed on AWS EC2 instances. The actual connection URLs and browser URLs are displayed in the output of the databases.yml workflow after deployment.

Neo4j Ledger Database

Connection URL format: bolt://[neo4j_ledger_private_ip]:7687

Browser URL format: https://[domain]/neo4jbrowser-ledger-login

Note: Replace [neo4j_ledger_private_ip] and [domain] with the actual values from the workflow output.

Neo4j Search Database

Connection URL format: bolt://[neo4j_search_private_ip]:7687

Browser URL format: https://[domain]/neo4jbrowser-search-login

Note: Replace [neo4j_search_private_ip] and [domain] with the actual values from the workflow output.

Finding the Actual URLs

To get the actual URLs for the production environment:

  1. Run the databases.yml workflow in GitHub Actions
  2. Check the output of the "Print Database Infrastructure Outputs" step
  3. Look for the "Neo4j LedgerSpace Instance" and "Neo4j SearchSpace Instance" sections to find the private IPs
  4. Look for the "Neo4j Browser Proxy URLs" section to find the browser URLs
