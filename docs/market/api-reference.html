Member Endpoints

These endpoints manage member profiles and vendor settings in the Vimbiso Market.

/editMember

Update a member's profile information including vendor-specific details.

Parameters:
  • firstname: string
  • lastname: string
  • memberHandle: string
  • profile_picture_200_jpg: string - ID of node to link with PROFILE_PICTURE_200_JPG relationship
  • profile_picture_600_jpg: string - Same as above
  • profile_picture_original_jpg: string - Same as above
  • vendorBio: string
Example Request:
{
  "firstname": "Munya",
  "lastname": "Farmer",
  "memberHandle": "munyaFarmer",
  "profile_picture_200_jpg": "asset-123-200",
  "profile_picture_600_jpg": "asset-123-600",
  "profile_picture_original_jpg": "asset-123-original",
  "vendorBio": "I grow the freshest tomatoes in Harare."
}

/sellInMarket

Enable or disable vendor functionality for a member.

Operations:
  • Sets (:Member { vendor: true|false })
  • When set to true, creates if not existing:
    • (:accountInternal { accountName: "Onboarded Assets", accountType: "PRODUCTION" })
    • (:accountInternal { accountName: "Profile Pictures", accountType: "DIGITAL_ASSET" })
Example Request:
{
  "vendor": true
}

Account Endpoints

These endpoints manage accounts used for tracking products, inventory, and transactions in the Vimbiso Market.

/editAccount

Update an existing exchange account's details.

Parameters:
  • accountName: string
  • accountHandle: string
  • defaultDenom: string - Limited to current denoms
Example Request:
{
  "accountName": "Fresh Tomatoes",
  "accountHandle": "freshTomatoes",
  "defaultDenom": "USD"
}

/createAccountInternal

Create a new internal account for tracking products or production.

Parameters:
  • accountName: string
  • defaultDenom: string - Limited to current denoms
  • accountType: string - One of CONSUMPTION, PRODUCTION, DIGITAL_ASSET, PHYSICAL_ASSET
Example Request:
{
  "accountName": "Tomato Production",
  "defaultDenom": "USD",
  "accountType": "PRODUCTION"
}

/editAccountInternal

Update an existing internal account's details.

Parameters:
  • accountName: string
  • defaultDenom: string - Limited to current denoms
Example Request:
{
  "accountName": "Organic Tomato Production",
  "defaultDenom": "USD"
}

/deleteAccountInternal

Delete an internal account.

Parameters:
  • accountID: string
Example Request:
{
  "accountID": "account-123"
}

AssetMarker Endpoints

These endpoints manage digital assets such as product images and their relationships in the system.

/addAssetMarker

Create a new asset marker in the system.

Parameters:
  • assetName: string
  • Arbitrary key/value pairs and/or neo4j-safed objects up to max size of 2kb
  • Optional link/key to access any data stored in S3 bucket
  • AssetMarkerData: Object - Data for AssetMarkers created when a connected credex is accepted
Example Request:
{
  "assetName": "Tomato Product Image",
  "description": "Fresh red tomatoes from Munya's farm",
  "s3Key": "products/tomatoes/main.jpg",
  "AssetMarkerData": {
    "productType": "vegetable",
    "harvestDate": "2025-03-01"
  }
}

/uploadAndOptimizeJpg

Upload a JPG image, optimize it, and create the necessary asset markers and relationships.

Parameters:
  • Requires jpg, name, DR accountID, optional CR accountID (default MERGE "Onboarded Assets")
Operations:
  • Saves AssetMarker with CR and DR relationships
  • Creates 200px and 600px versions with the same CR and DR relationships
  • Creates USED_IN relationship from original upload to resized/optimized images
Example Request:
{
  "jpg": "[binary data]",
  "name": "tomato_product_image",
  "drAccountID": "tomatoes-account-123",
  "crAccountID": "onboarded-assets-account-456"
}

/connectAsset

Connect an asset marker to another node with a specified relationship.

Parameters:
  • assetID: string
  • connectedID: string - ID of node to connect
  • relName: string - One of [:USED_IN|PROFILE_PIC_ORIGINAL_JPG|PROFILE_PIC_200_JPG|PROFILE_PIC_600_JPG]
Example Request:
{
  "assetID": "asset-123",
  "connectedID": "member-456",
  "relName": "PROFILE_PIC_200_JPG"
}

/disconnectAsset

Remove a relationship between an asset marker and another node.

Parameters:
  • assetID: string
  • connectedID: string - ID of node to disconnect
  • relName: string - One of [:USED_IN|PROFILE_PIC_ORIGINAL_JPG|PROFILE_PIC_200_JPG|PROFILE_PIC_600_JPG]
Example Request:
{
  "assetID": "asset-123",
  "connectedID": "member-456",
  "relName": "PROFILE_PIC_200_JPG"
}

Invoice Endpoints

These endpoints manage invoices for transactions in the Vimbiso Market.

/generateInvoice

Generate an invoice for a transaction in the Vimbiso Market.

Parameters:
  • payment accountID: string - Account
  • AssetMarkerData: Object - Data for AssetMarkers created when a connected credex is accepted
Returns:
  • Link based on invoiceID for client to generate invoiceQR
Example Request:
{
  "payment accountID": "tomatoes-account-123",
  "AssetMarkerData": {
    "items": [
      {
        "name": "Fresh Tomatoes",
        "quantity": 5,
        "unit": "kg",
        "price": 4.00,
        "total": 20.00
      }
    ],
    "total": 20.00,
    "currency": "USD",
    "notes": "Farm fresh tomatoes"
  }
}
Example Response:
{
  "invoiceID": "invoice-789",
  "invoiceQRLink": "https://vimbisopay.com/invoice/qr/invoice-789"
}
