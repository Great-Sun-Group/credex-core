🚨 DNS Troubleshooting

Vimbiso Domain Issues

The vimbisopay.africa domain may show DNS configuration issues:

Common Problem

DNS record incorrectly created as vimbisopay.africa.mycredex.app instead of vimbisopay.africa

Root Cause

  • vimbisopay.africa not configured as separate zone in Cloudflare
  • Domain nameservers not pointing to Cloudflare
  • Cloudflare treating it as subdomain of mycredex.app

Solution Steps

  1. Add vimbisopay.africa as separate zone in Cloudflare dashboard
  2. Get Cloudflare nameservers for vimbisopay.africa
  3. Update domain registrar to use Cloudflare nameservers
  4. Delete incorrect DNS record: vimbisopay.africa.mycredex.app
  5. Create correct DNS record: vimbisopay.africa → tunnel
  6. Wait for DNS propagation (24-48 hours)

🔄 Additional Domain Setup

Adding vimbisopay.co.zw

To add additional domains to the existing Vimbiso tunnel:

  1. Add domain to Cloudflare as new site
  2. Update nameservers at domain registrar
  3. Create CNAME records:
    TypeNameTarget
    CNAME@8ef6eec4-04dd-4d58-bd90-f8c3d180df6b.cfargotunnel.com
    CNAMEwww8ef6eec4-04dd-4d58-bd90-f8c3d180df6b.cfargotunnel.com
    CNAMEapi8ef6eec4-04dd-4d58-bd90-f8c3d180df6b.cfargotunnel.com
  4. Update tunnel configuration to include new domain
  5. Restart tunnel if needed

📞 Support Commands

Tunnel Management

# List all tunnels
.\cloudflared.exe tunnel list

# Delete a tunnel (if needed)
.\cloudflared.exe tunnel delete <tunnel-name>

# Update DNS routing
.\cloudflared.exe tunnel route dns <tunnel-name> <hostname>

Configuration Validation

# Test configuration
.\cloudflared.exe tunnel --config cloudflared-config.yml ingress validate

# Check tunnel health
.\cloudflared.exe tunnel --config cloudflared-config.yml ingress rule <hostname>
