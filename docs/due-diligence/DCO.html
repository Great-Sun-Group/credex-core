Daily Credcoin Offering (DCO)

The Daily Credcoin Offering (DCO) is a crucial component of the Credex ecosystem that runs every 24 hours at midnight UTC, while most of the world's population centres are in darkness.

DCO Process Overview

The DCO process follows these key steps:

  1. Check if the Minute Transaction Queue (MTQ) is running and wait if it is. This ensures no transaction processing conflicts.
  2. Set the DCOrunningNow flag and fetch the current and next date.
  3. Perform an end-of-day backup to ensure data integrity before proceeding.
  4. Process defaulting unsecured credexes and expire pending offers/requests.
  5. Find and validate DCO participants:
    • Identify accounts with active DCO_GIVE templates
    • Verify secured balances are sufficient for participation
    • Calculate total DCO contributions in both CXX and XAU
  6. Fetch current exchange rates from external sources:
    • OpenExchangeRates API for major currency pairs
    • Convert all rates to XAU (gold) basis
  7. Calculate new CXX rates based on:
    • Total DCO contributions
    • Number of confirmed participants
    • Current market exchange rates
  8. Create a new daynode with the updated CXX rates.
  9. Update all credex and asset balances across the system to reflect new rates.
  10. Process DCO transactions:
    • Create and accept DCO give transactions from participants
    • Create and accept DCO receive transactions to participants
  11. Perform a start-of-day backup for the new day.

Exchange Rate Calculations

The DCO process uses a focused system of exchange rate calculations to maintain value consistency across different denominations. All amounts in the credex ecosystem are stored in CXX alongside a companion CXXmultiplier that expresses the amount in its face value denomination.

Rate Conversion Process

  1. Initial Rate Fetching:
    • Fetch USD-based rates from OpenExchangeRates API
    • Convert all rates to XAU (gold) basis for stability
    • Calculate denomsInXAU for each currency: 
      denomsInXAU[currency] = USDbaseRates[currency] / USDbaseRates.XAU
  2. DCO Contribution Processing:
    • Convert each participant's contribution to XAU: 
      DCOinXAU += DCOgiveInDenom / denomsInXAU[DCOdenom]
    • Track total contributions in both CXX and XAU
  3. New CXX Rate Calculation:
    • Calculate new CXX value in XAU: 
      nextCXXinXAU = DCOinXAU / numberConfirmedParticipants
    • Calculate day-over-day CXX value change: 
      CXXprior_CXXcurrent = DCOinCXX / numberConfirmedParticipants
    • Calculate new CXX rates for all denominations: 
      newCXXrates[denom] = 1 / (nextCXXinXAU * denomsInXAU[denom])

Balance Updates

After new rates are established, all balances in the system must be updated to maintain their relative value. This process handles both CXX-denominated and currency-denominated values:

CXX-Denominated Values

For credexes and other values denominated in CXX:

  • Divide all CXX values by CXXprior_CXXcurrent to maintain relative value
  • CXXmultiplier remains 1 for CXX-denominated values
  • This adjustment ensures CXX values remain true to the flow of natural resource value per person

Currency-Denominated Values

For credexes and other values denominated in currencies:

  • Note the face value (CXX value / CXXmultiplier)
  • Divide CXX value by CXXprior_CXXcurrent
  • Update CXXmultiplier to maintain face value in denomination
  • This preserves accounting truth in local currency while maintaining system-wide value relationships

Transaction Processing

The DCO process handles two types of transactions using recurring templates for authorization:

DCO Give Transactions

These transactions represent participants giving value to others based on their consumption of natural resources:

  • Must be secured credexes backed by real assets
  • Denominated in participant's chosen currency
  • Amount determined by participant's DCO_GIVE template
  • Automatically created and accepted using template authorization

DCO Receive Transactions

These transactions distribute value equally to all participants:

  • Always denominated in CXX
  • Amount is always 1.000 CXX per participant
  • Secured against pooled DCO give assets
  • Automatically created and accepted using same template authorization
