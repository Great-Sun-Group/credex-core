Firebase Cloud Messaging Token Generator

Setup Instructions:

  1. Start a local server in the tests/manual directory: 
    cd tests/manual
python3 -m http.server 8000
  2. Open http://localhost:8000/get-fcm-token.html
  3. If notifications were previously blocked:
    • Click the lock/info icon in the address bar
    • Find "Notifications" permission
    • Change from "Block" to "Ask" or "Allow"
    • Reload the page
  4. Click the "Request Permission & Get Token" button below
  5. When prompted, click "Allow" for notifications
