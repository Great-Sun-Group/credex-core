Image Quality Testing

Testing the Image Quality Validation Implementation

Overview

This guide covers testing the image quality validation features implemented for ID verification, including face detection, document edge detection, blur detection, and lighting assessment.

Test Structure

The test suite is organized into three main components:

  • faceDetection.test.ts - Tests for face detection and validation
  • documentDetection.test.ts - Tests for document edge detection and alignment
  • imageQuality.test.ts - Tests for blur detection and lighting assessment

Running Tests

Execute the image quality test suite using: 

npm test tests/api/verification/utils

Or run specific test files: 

npm test tests/api/verification/utils/faceDetection.test.ts
npm test tests/api/verification/utils/documentDetection.test.ts
npm test tests/api/verification/utils/imageQuality.test.ts

Test Requirements

The test suite requires:

  • Node.js and npm installed
  • Jest test framework (included in project dependencies)
  • Sharp image processing library
  • OpenCV.js for face and document detection

Test Data

Test images should be placed in tests/fixtures/verification/images/ with the following files:

  • valid-selfie.jpg - Clear face photo (1024x768)
  • valid-document.jpg - Clear ID document (1024x768)
  • blurry-image.jpg - Intentionally blurred image
  • dark-image.jpg - Underexposed image
  • bright-image.jpg - Overexposed image
  • low-res-image.jpg - Low resolution image (320x240)

Performance Testing

Performance tests verify that image processing completes within acceptable timeframes: 

test('completes validation within 500ms', async () => {
  const startTime = Date.now();
  await validateImage(testImageBuffer, 'selfie');
  const duration = Date.now() - startTime;
  expect(duration).toBeLessThan(500);
});

Error Handling

Tests verify proper error handling for various scenarios:

  • Invalid image formats
  • Processing failures
  • Memory constraints
  • Timeout conditions

Audit Logging

Tests verify that appropriate audit events are logged: 

expect(auditLogger.log).toHaveBeenCalledWith({
  eventType: 'IMAGE_VALIDATION',
  timestamp: expect.any(String),
  data: expect.objectContaining({
    isValid: expect.any(Boolean),
    dimensions: expect.any(Object)
  })
});
