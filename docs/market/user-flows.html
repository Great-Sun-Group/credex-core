Munya the farmer adds a vendor profile pic

This flow demonstrates how a member can add a profile picture to their vendor profile. The system handles image uploads, optimization, and storage in the S3 bucket while maintaining proper accounting relationships in the database.

Process Details

  1. User navigates to the Edit Member Profile screen
  2. User selects the Add Image option
  3. System calls the uploadAndOptimizeJpg API endpoint
  4. System creates optimized versions of the image (200px and 600px)
  5. System calls the connectAsset API endpoint to link the images to the member profile
  6. Images are stored in the S3 bucket with proper relationships in the database

Munya lists tomatoes in the Vimbiso Market

This flow shows how a vendor can list a product (tomatoes) in the Vimbiso Market. The system creates the necessary account structures and asset relationships to track the product.

Process Details

  1. User creates a new product listing (tomatoes)
  2. System calls the addAccountInternal API endpoint to create the product account
  3. User uploads product images
  4. System calls the uploadAndOptimizeJpg API endpoint
  5. System creates optimized versions of the images
  6. System calls the connectAsset API endpoint to link the images to the product account

Munya harvests $100 of tomatoes and tracks with production account

This flow demonstrates how a vendor can track inventory production in the system. The vendor records the harvesting of tomatoes and updates the inventory accordingly.

Process Details

  1. User navigates to the Add Account screen
  2. User creates a PRODUCTION account called "produceGrown"
  3. System calls the addAccountInternal API endpoint
  4. User navigates to the Add Adjusting Entry screen
  5. User records the harvesting of $100 worth of tomatoes
  6. System calls the addAssetMarker API endpoint
  7. System creates the necessary accounting relationships

Munya creates an invoice for $20 of tomatoes which are purchased by Farai the merchant

This flow illustrates the invoicing and payment process between a vendor and a purchaser. Munya creates an invoice for tomatoes, which Farai pays using a credex.

Process Details

  1. Munya navigates to the Vimbiso Store screen
  2. Munya creates an invoice for $20 of tomatoes
  3. System calls the generateInvoice API endpoint
  4. System displays a QR code for the invoice
  5. Farai scans the QR code
  6. Farai is directed to the Create Credex from Invoice screen
  7. Farai confirms the payment
  8. System calls the createCredex API endpoint with the invoiceID
  9. System creates the Credex with a GLid field
  10. System creates an EXECUTES relationship from the Credex to the Invoice
  11. System creates AssetMarker nodes with the same GLid to represent the accounting entries
