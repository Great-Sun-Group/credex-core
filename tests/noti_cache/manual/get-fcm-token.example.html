Firebase Cloud Messaging Token Generator

Setup Instructions:

  1. Copy get-fcm-token.example.html to get-fcm-token.html
  2. Copy firebase-messaging-sw.example.js to firebase-messaging-sw.js
  3. Update both files with your Firebase configuration:
    • apiKey
    • authDomain
    • projectId
    • storageBucket
    • messagingSenderId
    • appId
    • vapidKey (from Firebase Console > Project Settings > Cloud Messaging > Web Push certificates)
  4. Start a local server in the tests/manual directory: 
    cd tests/manual
python3 -m http.server 8000
  5. Open http://localhost:8000/get-fcm-token.html
  6. If notifications were previously blocked:
    • Click the lock/info icon in the address bar
    • Find "Notifications" permission
    • Change from "Block" to "Ask" or "Allow"
    • Reload the page
  7. Click the "Request Permission & Get Token" button below
  8. When prompted, click "Allow" for notifications
