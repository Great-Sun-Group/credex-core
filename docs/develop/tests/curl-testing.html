Curl Testing

Examples of curl commands to test the credex-core API endpoints directly. Login and onboard routes are the only that do not require a token.

Login

curl -X POST http://localhost:3000/login -H "Content-Type: application/json" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"phoneNumber": "1234567890"}'

Onboard Member

curl -X POST http://localhost:3000/onboardMember -H "Content-Type: application/json" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"firstname": "Fortunate", "lastname": "Vendor", "phone": "1234567890", "defaultDenom": "USD"}'

Create Credex

curl -X POST http://localhost:3000/createCredex -H "Content-Type: application/json" -H "Authorization: Bearer token" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"issuerAccountID": "issuerAccountID", "receiverAccountID": "receiverAccountID", "currency": "USD", "amount": "20.00", "credexType": "PURCHASE", "credexSubType": "OFFERS", "clearable": true, "invoiceID": "invoiceID"}'

Create Invoice

curl -X POST http://localhost:3000/generateInvoice -H "Content-Type: application/json" -H "Authorization: Bearer token" -H "x-client-api-key: $CLIENT_API_KEY" -d '{"paymentAccountID": "paymentAccountID", "invoice": {"items": [{"name": "Fresh Tomatoes", "quantity": 2, "unit": "kg", "price": 10, "total": 20}], "total": 20, "currency": "USD"}}'
